# 02 — الأساسيات: Hello World والمتغيرات والأنواع

> **TL;DR**
> - نقطة الدخول الافتراضية `fn main()`، ويمكن اختيار أي دالة بـ `entry fn name()` أو `--entry name`، وكل جملة تنتهي بـ `;`.
> - `print()` **لا يضيف سطراً جديداً** — اكتب `"\n"` بنفسك.
> - أربع صيغ لتعريف المتغيّر: `let x = 5;` و `let int x = 5;` و `let x: int = 5;` و `int x = 5;`.
> - `int` هو 64-بت دائماً، و `float` (32-بت) يُطبع بتقريب إلى أربع منازل مع حذف الأصفار الزائدة.
> - التعليقات: `//` لسطر واحد و `/* ... */` لعدة أسطر.

**حالة الدعم:** ✅ مستقر

## أول برنامج

```c
fn main() {
    print("Hello, Magnetar!\n");
}
```

- `fn main()` هي **نقطة الدخول الافتراضية**. لاختيار دالة بديلة ضع `entry` قبل `fn`:
  ```c
  entry fn start() {
      print("hello\n");
  }
  ```
  أو مرّر اسمها عند البناء: `magc app.mg --entry start`. إذا لم توجد الدالة المختارة يفشل التوليد برسالة واضحة.
- بدون `main` أو دالة `entry` لا تُنفَّذ الجمل على المستوى الأعلى؛ لذلك عرّف نقطة دخول دائماً.
- `print()` دالة مدمجة تطبع قيمتها. **لا تضيف سطراً جديداً**، لذا نضيف `"\n"`.

## الأنواع الأساسية

| النوع | الوصف | أمثلة قيم |
|-------|-------|-----------|
| `int` | عدد صحيح **64-بت** بعلامة | `42`, `-7`, `0` |
| `float` | عدد عشري (32-بت) | `3.14`, `-2.5` |
| `bool` | منطقي | `true`, `false` |
| `char` | محرف واحد | `'A'`, `'9'`, `'\n'` |
| `string` | نص | `"hello"` |
| `void` | لا قيمة | — |

هناك أيضاً أنواع أخرى (مؤشرات، مصفوفات، جنيسة) تُشرح في الفصول اللاحقة.

## تعريف المتغيرات

### الصيغة الحديثة: `let`

```c
let i = 10;          // int (استدلال تلقائي)
let f = 2.5;         // float
let b = true;        // bool
let c = 'Z';         // char
let s = "text";      // string
```

### تحديد النوع صراحةً

صيغتان مقبولتان:

```c
let int x = 5;       // النوع أولاً
let y: int = 7;      // النوع بعد النقطتين
```

### التعريف ثم الإسناد لاحقاً

```c
let total: int;
total = x + y;
```

### الصيغة الكلاسيكية (مثل C)

```c
int old = 1;
float pi = 3.14;
```

> جميع الصيغ مدعومة: `let name = value;`، `let type name = value;`، `let name: type = value;`، و `type name = value;`.

## الإسناد

```c
let n = 100;
n = 50;      // إسناد بسيط

n -= 3;

n ^= 5;
```

## الطبع

`print()` تقبل أي من الأنواع الأساسية مباشرة:

```c
fn main() {
    print("number = "); print(42);    print("\n");
    print("bool   = "); print(true);  print("\n");
    print("char code = "); print('M'); print("\n");
    print("float  = "); print(3.5);   print("\n");
    print("string = "); print("hi");  print("\n");
}
```

الناتج:

```
number = 42
bool   = true
char code = 77
float  = 3.5
string = hi
```

> **كيف تُطبع الأعداد العشرية فعلياً؟** الجزء الصحيح، ثم نقطة، ثم الكسر **مُقرَّباً
> إلى أربع منازل** مع حذف الأصفار الزائدة من النهاية (يبقى رقم واحد على الأقل):
>
> | القيمة | الناتج |
> |--------|--------|
> | `3.5` | `3.5` |
> | `0.1` | `0.1` |
> | `1024.0` | `1024.0` |
> | `10.0 / 3.0` | `3.3333` |
> | `-2.5` | `-2.5` |
>
> الإشارة السالبة تُطبَّق على قيمة الفاصلة العائمة نفسها (لا على البتات الخام).
> السلوك مغطّى بالاختبار `f01_float_printing`.

## ملاحظات مهمة

- كل جملة تنتهي بـ `;`.
- **ترتيب التعريفات لا يهم داخل نفس الملف**: استدعاء دالة معرَّفة **بعد** `main` يعمل بشكل صحيح،
  لأن المترجم يجمع الرموز أولاً ثم يولّد الشيفرة. (الاستثناء: الدوال المدمجة تحتاج `extern fn` — راجع [09_builtins.md](09_builtins.md).)
- لا يفترض المترجم نوعاً `auto` إلا عند استخدام `let` مع قيمة ابتدائية.
- ⚠️ **القرار طويل المدى**: لا يوجد نوع `double` بعد؛ `float` هو 32-bit IEEE،
  واستخدام `double` يُنتج الآن خطأ تصريح واضحاً بدل قبوله كنوع مجهول وطباعة بتاته الخام.
  **لا تستخدم `float` للحساب الحساس** (مبالغ مالية، مقارنات مساواة، تراكم طويل) —
  استخدم `int` بـ خانات ثابتة، أو قارن بفارق سماحي. راجع
  [12_notes_and_limitations.md](12_notes_and_limitations.md).
