# 📱 مكتبة التحكم بالهاتف عبر USB — `lib/adb.mg`

**الإصدار:** v1.0  
**الوصف:** مكتبة Magnetar للتحكم بالهاتف عبر ADB (Android Debug Bridge)  
**الاعتماديات:** `lib/gui.mg` (للعرض)، `lib/image.mg` (لفك PNG)

## 📋 خطة التطوير (Roadmap)

### المرحلة 1 — الأساس ✅ (الحالية)

| المهمة | الحالة | الوصف |
|--------|--------|-------|
| `adb_path()` | ✅ | اكتشاف مسار ADB تلقائياً |
| `adb_available()` | ✅ | التحقق من وجود ADB |
| `adb_exec()` | ✅ | تنفيذ أمر ADB عبر fork+pipe+execve وإرجاع الناتج |
| `adb_exec_raw()` | ✅ | تنفيذ أمر ADB وإرجاع بيانات ثنائية (لقطات الشاشة) |
| `adb_devices()` | ✅ | عرض الأجهزة المتصلة |
| `adb_shell()` | ✅ | تنفيذ أمر shell على الهاتف |
| `adb_get_prop()` | ✅ | قراءة خصائص الهاتف (الموديل، الإصدار...) |

### المرحلة 2 — التقاط الشاشة

| المهمة | الحالة | الوصف |
|--------|--------|-------|
| `adb_screencap_png()` | 📋 | التقاط لقطة PNG عبر `adb exec-out screencap -p` |
| `adb_screencap_raw()` | 📋 | التقاط بيانات خام RGBA عبر `adb exec-out screencap` |
| `adb_screen_size()` | 📋 | قراءة دقة شاشة الهاتف |
| فك تشفير PNG | 📋 | استخدام `lib/image.mg` لفك PNG إلى بكسلات RGBA |
| تحجيم الصورة | 📋 | تصغير الإطار ليتناسب مع نافذة العرض |

### المرحلة 3 — البث المتواصل (Streaming)

| المهمة | الحالة | الوصف |
|--------|--------|-------|
| `adb_stream_start()` | 📋 | بدء بث `screenrecord --output-format=h264` عبر pipe |
| `adb_stream_read()` | 📋 | قراءة إطار واحد من البث |
| `adb_stream_stop()` | 📋 | إيقاف البث وتنظيف العمليات |
| فك H264 | 📋 | استخدام ffmpeg عبر pipe لتحويل H264 → rawvideo |
| حلقة 30 FPS | 📋 | عرض الإطارات بشكل متواصل في نافذة gui.mg |

### المرحلة 4 — التحكم بالمدخلات

| المهمة | الحالة | الوصف |

| `adb_input_swipe()` | ✅ | إرسال سحب من نقطة إلى نقطة |
| `adb_input_keyevent()` | ✅ | إرسال مفتاح (رجوع، رئيسية، صوت...) |
| `adb_input_text()` | ✅ | إرسال نص مكتوب |
| تحويل إحداثيات | 📋 | تحويل إحداثيات نافذة gui.mg إلى إحداثيات شاشة الهاتف |

## 🔧 مرجع API — المرحلة 1

### التهيئة والاكتشاف

```c
// التحقق من وجود ADB
if (adb_available()) {
    print("ADB متوفر!\n");
}

// عرض المسار المكتشف
string path = adb_path();
print(path); // "/usr/bin/adb"
```

### تنفيذ الأوامر

```c
// تنفيذ أمر ADB وإرجاع الناتج كنص
string result = adb_exec("devices");
print(result);

// تنفيذ أمر shell على الهاتف
string output = adb_shell("ls /sdcard/");
print(output);

// قراءة خصائص الجهاز
string model = adb_get_prop("ro.product.model");
string version = adb_get_prop("ro.build.version.release");
print("الموديل: "); print(model);
print("الإصدار: "); print(version);
```

### التحكم بالمدخلات

```c
// نقرة على الشاشة عند الإحداثيات (500, 800)
adb_input_tap(500, 800);

// سحب من (100,500) إلى (100,100) خلال 300 ميلي ثانية
adb_input_swipe(100, 500, 100, 100, 300);

// إرسال مفتاح (3 = HOME, 4 = BACK, 24/25 = VOLUME UP/DOWN)
adb_input_keyevent(3);  // زر الرئيسية

// كتابة نص
adb_input_text("Hello");
```

### إدارة الملفات

```c
// نسخ ملف إلى الهاتف
adb_push("/tmp/photo.jpg", "/sdcard/Download/photo.jpg");

// نسخ ملف من الهاتف
adb_pull("/sdcard/Download/file.txt", "/tmp/file.txt");

// تثبيت تطبيق
adb_install("/tmp/app.apk");

// إزالة تطبيق
adb_uninstall("com.example.app");
```

## 🏃 مثال سريع — معلومات الجهاز

```c
use "lib/adb.mg";

fn main() {
    if (!adb_available()) {
        print("خطأ: ADB غير موجود على النظام!\n");
        return;
    }

    print("=== معلومات الجهاز ===\n");

    // عرض الأجهزة المتصلة
    string devs = adb_devices();
    print("الأجهزة: "); print(devs); print("\n");

    // معلومات الجهاز
    string mdl = adb_get_prop("ro.product.model");
    print("الموديل: "); print(mdl); print("\n");

    string ver = adb_get_prop("ro.build.version.release");
    print("الإصدار: "); print(ver); print("\n");

    // إرسال نقرة تجريبية
    adb_input_tap(540, 960);
    print("تم إرسال نقرة تجريبية!\n");
}
```

## 📐 البنية التقنية الداخلية

### آلية fork+pipe+execve

```
1. إنشاء pipe: sys_pipe() → [read_fd, write_fd]
2. sys_fork() → عملية ابن
3. في الابن:
   - sys_dup2(write_fd, 1)  ← إعادة توجيه stdout إلى الـ pipe
   - sys_dup2(devnull, 2)   ← إخفاء stderr
   - sys_execve("/usr/bin/adb", argv, null)  ← استبدال العملية بـ ADB
4. في الأب:
   - sys_close(write_fd)    ← إغلاق طرف الكتابة
   - sys_read(read_fd, ...)  ← قراءة الناتج من الـ pipe
   - sys_wait4(pid, ...)     ← انتظار انتهاء العملية الابن
```

### قيود تقنية

> [!WARNING]
> - **البث المتواصل** (المرحلة 3) يتطلب فك H264 — سيتم عبر pipe إضافي إلى ffmpeg
> - **الإحداثيات** يجب تحويلها من دقة نافذة العرض إلى دقة شاشة الهاتف
> - **ADB** يجب أن يكون مثبتاً على النظام ومصادقاً مع الهاتف مسبقاً
> - **وضع تصحيح USB** يجب تفعيله على الهاتف

### تفعيل وضع التصحيح

1. فتح **الإعدادات** → **حول الهاتف**
2. النقر على **رقم الإصدار** 7 مرات لتفعيل خيارات المطور
3. فتح **خيارات المطور** → تفعيل **تصحيح USB**
4. توصيل الهاتف بالكابل والموافقة على طلب المصادقة
