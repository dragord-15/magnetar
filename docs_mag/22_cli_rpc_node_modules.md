# 22 — مكتبات CLI / RPC / Node (`lib/cli.mg`, `lib/rpc.mg`, `lib/node.mg`)

## `lib/cli.mg`

```mg
use "lib/cli.mg";
fn main(int argc, char** argv) -> int {
    if (cli_has_flag(argc, argv, "--help")) { print_str("help\n"); }
    string name = cli_get_option(argc, argv, "--name=", "default");
    int port = cli_get_option_int(argc, argv, "--port=", 8080);
    return 0;
}
```

الدوال: `cli_arg`, `cli_has_flag`, `cli_get_option`, `cli_get_option_int`, `cli_is_number`, `cli_print_kv`.

## `lib/rpc.mg`

JSON-RPC 2.0 عام فوق HTTP (يعتمد `lib/json.mg`, `lib/http.mg`).

```mg
use "lib/rpc.mg";
string req = rpc_build_request("ping", "[]", 1);
RpcClient c; c.init("http://127.0.0.1:29332"); c.set_auth("Authorization: Basic ...");
string resp = c.call("getblockcount", "[]", 1);
```

## `lib/node.mg`

هيكل بسيط لخدمات طويلة التشغيل.

```mg
use "lib/node.mg";
fn main() -> int {
    NodeConfig cfg = node_config_default("worker");
    NodeLoop loop; loop.init(cfg);
    while (loop.should_run()) {
        node_log("worker", "tick");
        loop.tick_done();
    }
    return 0;
}
```
