# 00 — نظرة عامة على لغة Magnetar (النسر)

> **TL;DR**
> - Magnetar لغة مترجَمة إلى **x86_64 أصلي**، تُنتج ملفات ELF مستقلة بلا اعتماد على libc.
> - نقطة الدخول الافتراضية `fn main()` (أو `entry fn name()` / `--entry name`)، والأنواع الأساسية `int`/`float`/`bool`/`char`/`string`.
> - القوالب `fixed<T,N>` و `dyn<T>` و `alloc<T>` مدمجة في النحو، والنظام متاح عبر syscalls مباشرة.
> - مسار الترجمة: Lexer → Parser → Semantic → IR → Backend.
> - ما هو مكتمل وما هو ناقص موثّق في [12_notes_and_limitations.md](12_notes_and_limitations.md).

**حالة الدعم:** ✅ مستقر

## ما هي اللغة؟

**Magnetar** (النسر / Falcon) هي لغة برمجة مترجَمة تمتلك:

- بنية نحوية (Syntax) حديثة مستوحاة من C و Rust و Swift.
- أنواعاً أساسية غنية (أعداد، نصوص، مؤشرات، مصفوفات، بنى، تعدادات).
- دعم قوالب جنيسة (Generics) في بعض الأنواع مثل `fixed<T, N>` و `alloc<T>`.
- نظام وحدات (Modules) بسيط عبر `use`.
- دعم مباشر لـ **syscalls** الخاصة بـ Linux كدوال مدمجة (ملفات، شبكات، عمليات، ...).
- خرج أصلي: **ELF 64-bit بلا اعتماد على libc** (الطبع والتنفيذ عبر syscalls مباشرة).

## الهدف من اللغة

اللغة مصممة لتكون:

1. **قريبة من العتاد** لكن بمظهر أنظف من C.
2. **متعددة المعالجات** على مستوى التصميم (x86_64 هو الناضج حالياً، arm64 و riscv قيد الإكمال).
3. **مكتفية ذاتياً** — لا تحتاج مكتبات خارجية عند التنفيذ.
4. **قابلة للتوسّع** بنظام واحدات واضح.

## نموذج التنفيذ

```
.mg source
   │
   ▼
┌──────────┐   ┌──────────┐   ┌───────────┐   ┌──────────┐   ┌───────────┐
│  Lexer   │──▶│  Parser  │──▶│ Semantic  │──▶│    IR    │──▶│  Backend  │
│ (tokens) │   │  (AST)   │   │ + Symbols │   │ (opt.)   │   │ (x86_64)  │
└──────────┘   └──────────┘   └───────────┘   └──────────┘   └─────┬─────┘
                                                                   │
                                                                   ▼
                                                             ELF executable
```

- **Lexer:** يحوّل النص إلى رموز (tokens).
- **Parser:** يبني شجرة AST.
- **Semantic + Symbols:** جمع الرموز وفحص الأنواع.
- **IR:** تمثيل وسيط قابل للتحسين.
- **Backend:** توليد تعليمات x86_64 ماشين-كود ثم كتابة ملف ELF.

## فلسفة اللغة

- **بساطة الكتابة:** `let` للتعريف، مع استدلال نوع تلقائي.
- **صيغتان مقبولتان:** الأسلوب الحديث `let x = 5;` والأسلوب الكلاسيكي `int x = 5;`.
- **براغماتية:** يمكنك الاقتراب من الـ syscalls مباشرة عند الحاجة (`sys_open`, `sys_read`, ...).
- **لا Magic:** الطبع لا يضيف سطراً جديداً، والأنواع الأعدادية 64-بت، والإزاحات بالبايت.

## مقابل اللغات الأخرى

| الجانب | Magnetar | C | Rust |
|--------|----------|---|------|
| النوع int | 64-bit دائماً | حسب المنصة | 32/64 حسب النوع |
| نقطة الدخول | `fn main()` أو `entry fn name()` | `int main()` | `fn main()` |
| الطبع | `print(x)` مدمج | `printf` | `println!` |
| الفواصل | `;` إلزامية | `;` إلزامية | `;` إلزامية |
| إدارة الذاكرة | `new`/`alloc<T>` + GC داخلي | يدوي | Ownership |
| syscalls | مدمجة كدوال | عبر libc | عبر libc/std |

## ما الذي يجعلها مميزة؟

- **الوصول المباشر للنظام:** أكثر من مئة syscall مدمجة كدوال جاهزة (ملفات، شبكات، epoll، ...).
- **لا Runtime خارجي:** البرنامج الناتج مستقل تماماً.
- **قوالب أنواع بسيطة:** `fixed<int,4>` و `alloc<int>(n)` مدمجتان في النحو.
