# 03 — العمليات والتعبيرات

> **TL;DR**
> - القسمة بين الأعداد الصحيحة **مُهملة الكسور**: `10 / 3 = 3`. استخدم `float` للقسمة العشرية.
> - المقارنات والعمليات المنطقية ترجع `1`/`0` لا `true`/`false`.
> - لكل عملية حسابية أو بتية صيغة مركّبة: `+=`, `-=`, `*=`, `/=`, `<<=`, `>>=`, `|=`, `&=`, `^=`.
> - ترتيب الأسبقية: `* / %` ← `+ -` ← الإزاحات ← البتية ← المقارنات ← `&&` ← `||` ← `?:`.
> - لا تخلط `int` و `float` في عملية واحدة دون مراجعة — وحّد النوع.

**حالة الدعم:** ✅ مستقر

## العمليات الحسابية

| العملية | الرمز | مثال | الناتج |
|---------|-------|------|--------|
| جمع | `+` | `2 + 3` | `5` |
| طرح | `-` | `10 - 4` | `6` |
| ضرب | `*` | `6 * 7` | `42` |
| قسمة | `/` | `10 / 3` | `3` (قسمة صحيحة) |
| باقي | `%` | `10 % 3` | `1` |
| سالب أحادي | `-` | `-7` | `-7` |

> قسمة الأعداد الصحيحة **قسمة صحيحة** (تُهمل الكسور). للقسمة العشرية استخدم `float`.

## المقارنات

ترجع `1` (صحيح) أو `0` (خطأ):

| العملية | الرمز |
|---------|-------|
| يساوي | `==` |
| لا يساوي | `!=` |
| أصغر | `<` |
| أصغر أو يساوي | `<=` |
| أكبر | `>` |
| أكبر أو يساوي | `>=` |

```c
print(3 < 5);    // 1
print(3 == 5);   // 0
```

## العمليات المنطقية

| العملية | الرمز |
|---------|-------|
| و (AND) | `&&` |
| أو (OR) | `\|\|` |
| نفي (NOT) | `!` |

```c
let ok = (x > 0) && (x < 100);
let notOk = !ok;
```

## العمليات البتية (Bitwise)

| العملية | الرمز | مثال | الناتج |
|---------|-------|------|--------|
| AND بتّي | `&` | `12 & 10` | `8` |
| OR بتّي | `\|` | `12 \| 10` | `14` |
| XOR بتّي | `^` | `12 ^ 10` | `6` |
| NOT بتّي | `~` | `~0` | `-1` |
| إزاحة يسار | `<<` | `1 << 10` | `1024` |
| إزاحة يمين | `>>` | `1024 >> 3` | `128` |

## الإسناد المركّب

جميع العمليات الحسابية والبتية لها صيغة مركّبة:

```c
n += 8;    n -= 3;    n *= 2;    n /= 11;
n <<= 3;   n >>= 2;   n |= 1;    n &= 30;   n ^= 5;
```

## الزيادة والنقصان

```c
i++;    // زيادة بمقدار 1
i--;    // نقصان بمقدار 1
```

## المعامل الثلاثي (Ternary)

```c
let max = (a > b) ? a : b;
```

## أسبقية العمليات

من الأعلى إلى الأدنى:

```
الأقواس  ( )
الضرب/القسمة/الباقي        * / %
الجمع/الطرح                + -
الإزاحة                    << >>
AND بتّي                   &
XOR بتّي                   ^
OR بتّي                    |
المقارنات                  == != < <= > >=
AND المنطقي                &&
OR المنطقي                 ||
المعامل الثلاثي            ?:
الإسناد                    = += -= ...
```

## مثال شامل

```c
fn main() {
    print("2 + 3 * 4   = "); print(2 + 3 * 4);   print("\n"); // 14
    print("(2 + 3) * 4 = "); print((2 + 3) * 4); print("\n"); // 20
    print("10 / 3      = "); print(10 / 3);      print("\n"); // 3
    print("10 % 3      = "); print(10 % 3);      print("\n"); // 1
    print("1 << 10     = "); print(1 << 10);     print("\n"); // 1024
    print("12 & 10     = "); print(12 & 10);     print("\n"); // 8
    print("1.5 + 2.25  = "); print(1.5 + 2.25);  print("\n"); // 3.7500
}
```

## ملاحظة على أنواع النتائج

- المقارنات والعمليات المنطقية ترجع قيماً عددية (`1`/`0`) عند الطبع، وهذا سلوك C.
- خلط `int` و `float` في عملية واحدة قد يُعطي نتائج يجب التحقق منها — يُفضّل توحيد النوع.
