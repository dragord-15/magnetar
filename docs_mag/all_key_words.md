# الكلمات المفتاحية في Magnetar

هذا الملف يصف جميع الكلمات المفتاحية النشطة والمدعومة رسمياً (86 كلمة مفتاحية) في لغة Magnetar بعد تنقيح وإزالة الكلمات غير المكتملة وتدعيم `any` و `as` و `volatile`.

جميع الكلمات المذكورة أدناه **تعمل ومُختبرة بالكامل** في المترجم `magc`.

---

## الكلمات المفتاحية المدعومة (86 كلمة)

| الكلمة | الوصف | ملاحظات |
|---|---|---|
| `int` | عدد صحيح 64-بت | النوع الافتراضي للأعداد |
| `float` | عدد عشري 32-بت | |
| `bool` | قيمة منطقية | قيمها `true` و `false` |
| `char` | حرف واحد (بايت) | |
| `string` | مؤشر إلى نص منتهٍ بـ NUL | قابل للطباعة والدمج والمقارنة |
| `void` | نوع إرجاع بلا قيمة | |
| `auto` | استنتاج نوع المتغير من المُهيِّئ | |
| `any` | نوع عام ديناميكي | خانة موسومة (16 بايت: القيمة + الوسم). تدعم العمليات الحسابية والمقارنات ديناميكياً حسب نوع القيمة، وتقبل التحويل عبر `as any` و `as Type` و `cast`، وتطبع بنوعها الفعلي |
| `byte` | عدد صحيح 8-بت | |
| `word` | عدد صحيح 16-بت | |
| `dword` | عدد صحيح 32-بت | |
| `qword` | عدد صحيح 64-بت | مرادف فعلي لـ `int` في الحجم |
| `fixed` | مصفوفة ثابتة الطول `fixed<T,N>` | |
| `slice` | مقطع `arr[start..end]` | الفهرسة تعمل |
| `array` | مرادف لـ `fixed` | |
| `ref` | نوع مرجعي `ref<T>` | مؤشر مرجعي آمن |
| `own` | نوع ملكية `own<T>` | مؤشر ملكية |
| `raw` | نوع خام `raw`/`raw<T>` | `raw<T>` يدعم الفهرسة مع `alloc<T>` |
| `null` | قيمة صفرية للمؤشرات | |
| `fn` | تعريف دالة | |
| `entry` | اختيار نقطة الدخول | بادئة قبل `fn` مثل `entry fn start()`، أو `--entry start`؛ الافتراضي `main` |
| `let` | تعريف متغير | |
| `struct` | تعريف بنية ذات حقول | |
| `class` | تعريف صنف بحقول ودوال | يدعم الوراثة والتغليف |
| `enum` | تعداد | وصول مؤهل `Enum.Member` |
| `union` | اتحاد | الحقول متراكبة عند الإزاحة 0 والحجم 8 بايت |
| `if` | شرط | |
| `else` | الفرع البديل للشرط | |
| `switch` | تبديل على قيمة | يُنفَّذ كسلسلة شروط محسّنة |
| `case` | حالة داخل `switch` | |
| `default` | الحالة الافتراضية في `switch` | |
| `for` | حلقة تكرار | تدعم الحلقات التقليدية و `for (int i in range(...))` |
| `while` | حلقة ما دام الشرط صحيحاً | |
| `do` | حلقة تنفَّذ مرة على الأقل | `do { ... } while (cond);` |
| `break` | الخروج من الحلقة | |
| `continue` | الانتقال للدورة التالية | |
| `return` | إرجاع قيمة/الخروج من الدالة | |
| `goto` | قفز إلى تسمية | التسمية بصيغة `label:` |
| `defer` | تأجيل تنفيذ جملة حتى نهاية الدالة | يُنفَّذ بترتيب عكسي (LIFO) |
| `match` | مطابقة قيمة مع أذرع `=>` | `_` هو الفرع الافتراضي |
| `new` | حجز عنصر على الكومة | |
| `delete` | تحرير مؤشر | |
| `use` | تضمين ملف أو مكتبة | التضمين الأساسي للوحدات، ويدعم التسمية البديلة `use X as Y;` |
| `export` | تصدير تعريف | يُكمل تجميع التعريف داخل الملف |
| `as` | تحويل الأنواع واسم بديل | يعمل لتحويل الأنواع مثل `x as float` و `x as any` و `a as int`، ويعمل كاسم بديل للموديول مع `use "file" as alias;` |
| `const` | قيمة ثابتة | يمنع إعادة الإسناد والتعديل وقت التصريف |
| `static` | تخزين ثابت/عام | يستمر بين الاستدعاءات |
| `extern` | تصريح دالة/رمز خارجي | يعمل مع دوال النظام ورموز المكتبات |
| `alloc` | حجز مصفوفة على الكومة `alloc<T>(n)` | |
| `free` | تحرير ذاكرة `alloc`/`new` | |
| `sizeof` | حجم النوع أو المتغير بالبايت | |
| `cast` | تحويل صريح `cast<T>(expr)` | |
| `half` | عدد عشري 32-بت | يُخزَّن كـ `float` (32-بت)؛ الطباعة والحساب والمصفوفات تعمل |
| `dyn` | مصفوفة ديناميكية `dyn<T>` | `push`/`pop`/`len`/`clear` والفهرسة والمُهيِّئ `{...}` تعمل |
| `range` | قيمة مدى `{start,end,step}` | نوع عام قابل للنسخ، حقول `.start`/`.end`/`.step`، ومدعوم في `for` |
| `typeof` | نوع تعبير | يدعم الأسماء والبنى والحقول والتعبيرات الحسابية |
| `nan` | ليس رقماً (NaN) | الطباعة المباشرة والحساب داخل `float` يعملان |
| `inf` | ما لا نهاية (Infinity) | الطباعة المباشرة والحساب داخل `float` يعملان |
| `inline` | تلميح تضمين دالة | يُقبل كتلميح للمترجم |
| `volatile` | وصول مباشر للذاكرة | يمنع تخزين القيمة في السجلات ويقرأ/يكتب مباشرة في الذاكرة |
| `register` | تلميح تخزين سريع | يُقبل كتلميح |
| `unsafe` | كتلة غير آمنة | تُقبل ككتلة برمجية للأكواد المتقدمة |
| `copy` | نسخ عميق للمحتوى المشار إليه | |
| `clone` | مرادف لـ `copy` | |
| `borrow` | أخذ عنوان قيمة | مثل `&` |
| `true` | قيمة منطقية صحيحة | |
| `false` | قيمة منطقية خاطئة | |
| `assert` | تحقق وقت التشغيل | عند الفشل يطبع `Assertion failed!` ويخرج بالرمز 1 |
| `throw` | إطلاق استثناء | |
| `try` | كتلة معالجة استثناءات محمية | |
| `catch` | التقاط استثناء | |
| `finally` | كتلة تنفَّذ دائماً بعد try/catch | |
| `this` | مرجع الكائن الحالي | |
| `self` | مرادف لـ `this` | |
| `super` | استدعاء/الوصول للصنف الأب | |
| `base` | مرادف لـ `super` | |
| `extends` | وراثة صنف | وراثة مفردة مدعومة للأصناف |
| `impl` | إضافة دوال وتطبيقات إلى نوع | |
| `tuple` | مجموعة حقول مرقمة | قراءة/كتابة `._0`/`._1` والطباعة المباشرة والإرجاع من الدوال |
| `print` | طباعة قيمة | تعمل مع جميع الأنواع الأساسية و `any` والنصوص |
| `move` | نقل قيمة وإفراغ المصدر | يعمل للمتغيرات والبنى وأعضائها وعناصر المصفوفات |
| `async` | كتلة غير متزامنة | عملية فرعية عبر `fork`؛ كتعبيـر تعيد PID |
| `await` | انتظار نتيجة مهمة | `await pid` أو `await` لأي عملية ابن |
| `spawn` | إنشاء مهمة غير متزامنة | تعيد PID في الأب و0 في الابن |
| `parallel` | تنفيذ متوازٍ | عملية فرعية يُنتظر انتهاؤها فوراً |
| `asm` | تجميع مضمّن (Inline Assembly) | يدعم mov/lea/حساب/syscall/مقارنة وسجلات x86-64 |
