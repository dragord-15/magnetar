# 07 — المؤشرات والمصفوفات وإدارة الذاكرة

> **TL;DR**
> - `&x` يأخذ عنواناً، و `*p` يقرأ/يكتب عبر المؤشر؛ والمؤشر المزدوج `**` مدعوم.
> - `fixed<T,N>` و `dyn<T>` مصفوفتان بمعامل `[]`، والمؤشرات تدعم `p[i]` بخطوة `sizeof(T)`.
> - `alloc<T>(n)` يحجز `n × sizeof(T)` بايت على الكومة، والفهرسة عليه بخطوة `sizeof(T)`.
> - `new T` يحجز عنصراً واحداً، و `free(ptr)` يحرّره — القواعد الكاملة في [المرجع الموحّد](#المرجع-الموحّد-alloctn).
> - لا يوجد فحص حدود افتراضي؛ استخدم `magc --bounds-check` للمصفوفات `fixed<T,N>` ذات الحجم الثابت.

**حالة الدعم:** ✅ مستقر

## المؤشرات

### التعريف والأخذ والإرجاع

```c
int x = 5;
int* p = &x;      // p يحمل عنوان x
print(*p);        // 5   (إرجاع)
*p = 9;           // كتابة عبر المؤشر
print(x);         // 9
```

- `&x` يأخذ عنوان `x`.
- `*p` يقرأ/يكتب القيمة المشار إليها.

### المؤشر المزدوج

```c
int** pp = &p;
print(**pp);      // 9
```

### تمرير المؤشر لدالة

```c
fn increment(int* v) -> int {
    *v = *v + 1;
    return *v;
}

int x = 5;
print(increment(&x));   // 6
print(x);               // 6
```

## المصفوفات

### مصفوفة ثابتة الطول `fixed<T, N>`

```c
fixed<int, 4> a = {10, 20, 30, 40};
print(a[2]);            // 30
print(a[0] + a[3]);     // 50
print(sizeof(a));       // 32 (4 عناصر × 8 بايت)
```

مصفوفة بدون تهيئة حرفية ثم إسناد عنصراً عنصراً:

```c
fixed<int, 3> b;
b[0] = 7;
b[1] = 8;
b[2] = 9;
print(b[0] + b[1] + b[2]);   // 24
```

### مصفوفات متعددة الأبعاد (نمط C)

يمكن كتابة الأبعاد بعد اسم المتغيّر كما في C، أو قبل الاسم، أو بتداخل
`fixed`:

```c
int grid[2][3] = {{1, 2, 3}, {4, 5, 6}};
int[2][3] typed = {{10, 20, 30}, {40, 50, 60}};
fixed<fixed<int, 3>, 2> nested = {{7, 8, 9}, {11, 12, 13}};

print(grid[1][2]);     // 6
print(typed[0][1]);    // 20
print(nested[1][0]);   // 11
print(sizeof(grid));   // 48 (6 عناصر × 8 بايت)
```

مثال كامل لمصفوفة ثلاثية الأبعاد `2 × 2 × 2` بالصيغ الثلاث:

```c
int cube[2][2][2] = {
    {{1, 2}, {3, 4}},
    {{5, 6}, {7, 8}}
};
int[2][2][2] typed = {
    {{10, 20}, {30, 40}},
    {{50, 60}, {70, 80}}
};
fixed<fixed<fixed<int, 2>, 2>, 2> nested = {
    {{100, 200}, {300, 400}},
    {{500, 600}, {700, 800}}
};

print(cube[0][1][0]);     // 3
print(cube[1][1][1]);     // 8
print(typed[1][0][1]);    // 60
print(nested[1][1][0]);   // 700
print(sizeof(cube));      // 64 (8 عناصر × 8 بايت)

cube[1][0][1] = 99;       // الكتابة داخل أي خانة
print(cube[1][0][1]);     // 99
```

الفهرسة `a[i][j][k]` تُحسب بنمط row-major، وكل خانة تشغل 8 بايت كما في
المصفوفات أحادية البعد. الفهرسة الجزئية (`grid[1]` على مصفوفة ثنائية
الأبعاد) تُرجع عنوان الصف لا قيمته. تدعم حقول البنى والكلاسات أيضاً:

```c
struct Grid { int cells[2][3]; }
struct Cube { int cells[2][2][2]; }

Grid g;
g.cells[1][2] = 22;

Cube c;
c.cells[1][0][1] = 77;
print(c.cells[1][0][1]);   // 77
```

### مصفوفات النصوص `string`

كل خانة في مصفوفة `string` تحمل مؤشراً إلى النص، لذا تعمل معها الطباعة
والدمج والمقارنة كأي نص عادي:

```c
let names: fixed<string, 3> = {"ali", "bob", "cat"};
print(names[0]);                  // ali
print(names[1] + "-" + names[2]); // bob-cat

string words[2] = {"hello", "world"};
words[1] = "Magnetar";
if (words[0] == "hello") print(words[1]);   // Magnetar

struct Basket { string items[3]; }
Basket b;
b.items[0] = "apple";
print(b.items[0]);                // apple
```

كما تدعم `dyn<string>` و `alloc<string>(n)` الفهرس `[i]` بنفس الصيغة.


### مصفوفة ديناميكية `dyn<T>`

```c
dyn<int> d = {1, 2, 3};
print(d[0]);   // 1
```

### مصفوفة على الكومة `alloc<T>(n)`

`alloc<T>(n)` تحجز `n` **عنصراً** من النوع `T` وتعيد مؤشراً إلى أولها. الفهرسة
المعتادة هي `p[i]`، وهي تكافئ `*(p + i * sizeof(T))`؛ الصيغة الصريحة مفيدة
عند التعامل مع إزاحات بايتية خام.

> ⚠️ **هذا النمط منخفض المستوى وغير آمن. لا يوجد فحص حدود وقت التشغيل للمؤشرات؛
> استخدم `fixed/dyn` كلما أمكن، واستعمل `alloc` عند الحاجة إلى ذاكرة صريحة.**

```c
int* block = alloc<int>(3);
block[0] = 1;
block[1] = 2;
block[2] = 3;

print(block[0]);       // 1
print(block[1]);       // 2
print(block[2]);       // 3

// تكافؤ صريح:
print(*(block + 1 * sizeof(int)));  // 2
```

> **تنبيه:** القواعد الكاملة — هل `n` عدد عناصر أم بايتات، وصيغة الفهرسة
> الصحيحة، وجدول الإزاحة لكل نوع — في قسم
> [المرجع الموحّد: alloc<T>(n)](#المرجع-الموحّد-alloctn) في نهاية هذا الفصل.
> لا تعتمد الشرح المختصر أعلاه.

## التخصيص الديناميكي

### `new`

```c
int* heap = new int;
*heap = 77;
print(*heap);    // 77
```

### الفرق بين new و alloc<T>

| الصيغة | ماذا تحجز | متى تستخدم |
|--------|-----------|------------|
| `new T` | عنصر واحد من النوع T بحجم `sizeof(T)` | عنصر مفرد |
| `alloc<T>(n)` | `n` عنصراً من النوع T | مصفوفة ديناميكية |
| `new Point` | **مدعوم**: بنية كاملة بحجم `sizeof(Point)` | عنصر بنية مفرد |

مثال مقارن:

```c
int* a = new int;          // 8 بايت
int* b = alloc<int>(3);    // 24 بايت (3 × 8)
```

> **دقّة الحساب:** الأرقام أعلاه هي **حجم البيانات** كما يبلّغ عنه `sizeof`.
> أما الحجز الفعلي في الذاكرة فيُضاف إليه **8 بايت ترويسة داخلية** لكل تخصيص
> (ليخزّن المترجم الحجم قبل `free`)، أي أن `new int` يحجز 16 بايت فعلياً،
> و `alloc<int>(3)` يحجز 32 بايت. وقد أُكِّد ذلك بالتشغيل عبر `strace`.

متى تستعمل أيّهما؟

| الحالة | الأداة |
|--------|--------|
| عنصر واحد عادي | `new T` |
| مصفوفة بطول معروف وقت الترجمة | `fixed<T, N>` أو `T a[N]` |
| مصفوفة متعددة الأبعاد | `T a[N][M]...` أو `fixed<fixed<T,M>,N>` |
| مصفوفة بطول محسوب وقت التشغيل | `alloc<T>(n)` |
| بنية واحدة على الكومة | `new Point` |

> ⚠️ **حالة خاصة — الوصول إلى حقول بنية عبر مؤشر:** في v3.5 يُقرأ الحقل
> بالنقطة **حتى لو كان المتغيّر مؤشراً**:
>
> ```c
> struct Point { int x; int y; };
>
> Point* p = new Point;
> p.x = 3;          // ✅ يعمل
> print(p.x);       // ✅ 3
> ```
>
> أمّا `p->x` فلا يُقبل أصلاً (المترجم يعطي خطأ نحوي عند `->`)، و `(*p).x`
> فيتسبّب في انهيار (SIGSEGV). لذلك استعمل **النقطة** دائماً مع المؤشرات.

### `alloc<T>(n)`

```c
int* block = alloc<int>(3);
```

### `free`

```c
free(heap);
```

## `sizeof`

يُعيد حجم النوع بالبايت:

```c
print(sizeof(int));     // 8
```

## مثال كامل

```c
fn increment(int* v) -> int {
    *v = *v + 1;
    return *v;
}

fn main() {
    int x = 5;
    int* p = &x;
    print(*p);         print("\n"); // 5
    *p = 9;
    print(x);          print("\n"); // 9

    int** pp = &p;
    print(**pp);       print("\n"); // 9

    print(increment(&x)); print("\n"); // 10
    print(x);             print("\n"); // 10

    int* heap = new int;
    *heap = 77;
    print(*heap);      print("\n"); // 77

    int* block = alloc<int>(3);
    *block = 1;
    *(block + 8) = 2;
    *(block + 16) = 3;
    print(*block); print(*(block + 8)); print(*(block + 16)); print("\n"); // 123

    fixed<int, 4> a = {10, 20, 30, 40};
    print(a[2]);          print("\n"); // 30
    print(a[0] + a[3]);   print("\n"); // 50

    fixed<int, 3> b;
    b[0] = 7; b[1] = 8; b[2] = 9;
    print(b[0] + b[1] + b[2]); print("\n"); // 24

    dyn<int> d = {1, 2, 3};
    print(d[0]);          print("\n"); // 1

    print(sizeof(int));   print("\n"); // 8
}
```

## إدارة الذاكرة الداخلية

المترجم يستخدم نظام **GC داخلي** (Garbage Collector) لبعض التخصيصات على مستوى المترجم نفسه
(`GC_init` / `GC_alloc` / `GC_collect` / `GC_shutdown`). أما ذاكرة البرنامج الناتج فتُدار بالطرق
المعروضة أعلاه (`new` / `alloc` / `free`).

## المرجع الموحّد: alloc<T>(n)

هذا القسم هو **المرجع الوحيد المعتمد** في التوثيق كله لسلوك `alloc<T>(n)`.
الفصلان [09](09_builtins.md) و [12](12_notes_and_limitations.md) يشيران إليه بدل إعادة الشرح،
حتى لا تتناقض الصياغة بين الفصول.

### 1) التعريف الدقيق

```c
int* block = alloc<int>(3);
```

- **`n` هو عدد العناصر**، وليس عدد البايتات. `alloc<int>(3)` تُحجز ثلاثة عناصر
  من نوع `int` — أي 24 بايت — لا ثلاثة بايتات.
- المؤشر المُعاد يشير إلى **أول عنصر**، لا إلى قاعدة الحجز.
- حجم الحجز الفعلي = `n × sizeof(T) + 8` بايت. البايتات الثمانية الأخيرة ترويسة
  داخلية (metadata) يخزّن فيها المترجم حجم الحجز ليستعمله في `free`، ويبدأ المؤشر
  المُعاد بعد هذه الترويسة مباشرة. `sizeof(int)=8`، `sizeof(float)=4`،
  `sizeof(char)=sizeof(bool)=1` على `x86_64` و `arm64` معاً.
- `free` يجب أن يستقبل **المؤشر نفسه** الذي أعادته `alloc`، لا مؤشراً داخل
  المصفوفة؛ لأن المترجم يرجع 8 بايت إلى الخلف ليصل إلى قاعدة الحجز قبل `munmap`.

> **مصدر التحقّق:** الحالتان `AST_ALLOC_EXPR` و `AST_NEW_EXPR` في كلا الـ
> backend يستعملان حجم العنصر نفسه الذي يُبلّغ عنه `sizeof(T)`؛ ثم يُضاف 8 بايت
> للترويسة، ثم `mmap`، ثم يُزاح المؤشر المُعاد 8 بايت. الفحص
> `tests/cases/s04_alloc_sizeof.mg` يغطّي `int`/`float`/`char`.

### 2) صيغة الفهرسة الصحيحة

المؤشر في Magnetar يدعم `p[i]` (يُترجم إلى `*(p + i * sizeof(T))`)، أما الحساب
`ptr + i` المباشر فيجمع البايتات كما هي (لا يضرب في حجم النوع تلقائياً). لذلك
الصيغة الصريحة المكافئة لقراءة أو كتابة العنصر رقم `i` هي:

```c
*(ptr + i * sizeof(T))
```

مثال كامل قابل للتشغيل:

```c
int* block = alloc<int>(3);

*(block + 0 * sizeof(int)) = 10;
*(block + 1 * sizeof(int)) = 20;
*(block + 2 * sizeof(int)) = 30;

print(*(block + 0 * sizeof(int)));   // 10
print(*(block + 1 * sizeof(int)));   // 20
print(*(block + 2 * sizeof(int)));   // 30
```

### 3) جدول الإزاحة لكل نوع

| النوع | sizeof | إزاحة العنصر i |
|-------|--------|----------------|
| int   | 8      | i * 8          |
| float | 4      | i * 4          |
| char  | 1      | i * 1          |
| bool  | 1      | i * 1          |

قيم `sizeof` أعلاه هي **العرض المنطقي** للنوع كما يُبلّغ عنه `sizeof(T)` في v3.5
(محقَّق منه بالتشغيل: `sizeof(int)=8`، `sizeof(float)=4`، `sizeof(char)=1`،
`sizeof(bool)=1`).

> **تناسق الحجز مع `sizeof`:** خطوة الفهرسة وحجم الحجز يستعملان نفس القيمة؛
> لا حاجة إلى حساب `i * 8` يدوياً للأنواع الأصغر. البنى تُقاس بحجم تخطيطها.
> استخدم `p[i]` أو `*(p + i * sizeof(T))` بالاتساق في القراءة والكتابة.

### 4) تحذير أمان

> ⚠️ **الفهرسة اليدوية بالبايت هشّة وغير آمنة؛ استخدم `fixed<T,N>` أو `dyn<T>`
> متى أمكن.**

أسباب الخطر عملياً:

- لا يوجد أي فحص لحدود (`bounds checking`) في `fixed` ولا في `dyn` ولا في المؤشرات.
- خطأ واحد في حساب الإزاحة (مثل `i * 4` بدل `i * 8`) يكتب في موضع خاطئ **دون
  أي رسالة من المترجم**.
- المؤشر لا يحمل أي معلومات عن الطول، فلا يستطيع المترجم أن يتحقق من صحتك.

البدائل المفضّلة:

```c
fixed<int, 4> a = {10, 20, 30, 40};   // طول معروف وقت الترجمة
print(a[2]);                          // 30

dyn<int> d = {1, 2, 3};               // طول معروف من المُهيِّئ
print(d[0]);                          // 1
```

ولحجز عنصر واحد فقط استعمل `new` بدل `alloc<T>(1)`:

```c
int* p = new int;
*p = 77;
print(*p);   // 77
free(p);
```
