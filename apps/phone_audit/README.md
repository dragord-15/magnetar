# Phone Audit - فحص أمن الهاتف عبر الكابل

أداة فحص أمني **للقراءة فقط** لهاتف Android متصل بالحاسوب عبر USB. تستخدم `lib/adb.mg` لقراءة الإعدادات وخصائص النظام، ثم تعرض تقريراً بمستويات الخطورة.

> استخدم الأداة فقط على هاتفك أو على جهاز تملك إذناً صريحاً بفحصه.

## المتطلبات
- `adb` مثبت على الحاسوب (`/usr/bin/adb` أو أحد المسارات المعتمدة في `lib/adb.mg`).
- هاتف Android متصل عبر USB، مع تفعيل USB debugging والموافقة على طلب ADB على شاشة الهاتف.

## البناء والتشغيل
```bash
./magc phone_audit/main.mg -o build/phone_audit
./build/phone_audit
./build/phone_audit --min-patch 2026-01-01   # تاريخ مرجعي مخصص للباتش الأمني
./build/phone_audit --help
```

## ما الذي تفحصه الأداة
1. **هوية الجهاز**: المسلسل، الموديل، المصنّع، إصدار Android، مستوى الباتش، نوع البناء، fingerprint.
2. **التعرض عبر التصحيح والشبكة**: USB debugging، Wireless debugging، خيارات المطوّر.
3. **سياسة تثبيت التطبيقات**: مصادر غير معروفة، خدمات إمكانية الوصول (Accessibility).
4. **تحصين المنصة**: Verified boot / bootloader، نوع البناء، SELinux، صلاحيات الـ ADB shell، التشفير، حداثة الباتش الأمني.
5. **مؤشرات تصعيد الصلاحيات**: `ro.debuggable`، `ro.secure`، `dm-verity`، حالة Bootloader، عمر النواة، قابلية كتابة `/system`، وجود `su` في `PATH`.

## مخرجات التقرير
- `[OK]` إعداد آمن، `[INFO]` معلومة للمراجعة، `[WARN]` يحتاج مراجعة، `[HIGH]` خطر مرتفع.
- في النهاية يظهر ملخص بعدد كل فئة.

## ملاحظات
- الأداة لا تعدّل أي إعداد على الهاتف ولا تثبّت أو تحذف تطبيقات.
- تفحص الأداة **مؤشرات التعرّض** لتصعيد الصلاحيات فقط؛ لا تحاول استغلال أي ثغرة ولا تنفّذ أي تصعيد فعلي.
- `[HIGH]` يعني إعداداً يسهّل التصعيد أو كسر سلسلة الإقلاع، وليس بالضرورة وجود ثغرة قابلة للاستغلال.
- تفعيل USB debugging ضروري لعمل الفحص؛ أوقفه بعد الانتهاء من لوحة خيارات المطوّر.
- `"null"` أو قيمة فارغة تعني أن الجهاز لا يوفّر الخاصية، وتُعرض كـ `(unknown)` أو `INFO`.
