# Falcon Phone Mirror

تطبيق سطح مكتب بلغة Magnetar لعرض شاشة هاتف Android متصل عبر USB والتحكم فيه مباشرة من الحاسوب.

## المتطلبات
- هاتف Android متصل عبر كابل USB، مع تفعيل **USB debugging** والموافقة على طلب ADB.
- `adb` و`ffmpeg` مثبتان على الحاسوب.
- بيئة عرض X متاحة، مثل `DISPLAY=:2`.

## البناء والتشغيل
```bash
./magc phone_mirror/main.mg -o build/phone_mirror
DISPLAY=:2 ./build/phone_mirror
```

## المزايا
- بث حي غير حاجز: التقاط الشاشة في عملية خلفية عبر `adb exec-out screencap -p` + `ffmpeg` دون تجميد الواجهة.
- تحجيم يحافظ على نسبة الأبعاد مع هوامش (`pad`) بدلاً من تشويه الصورة، وإخراج `BGRA` متوافق مع محرك الرسوم.
- نافذتان مستقلتان وقابلتان للتحريك: شاشة الهاتف ولوحة التحكم.
- تحديث تلقائي للشاشة، أو زر **Sync Now** عند الحاجة.
- لمس على شاشة الهاتف يُترجم إلى `adb input tap` بإحداثيات الجهاز الحقيقية.
- أزرار: Back / Home / Recent Apps، Power، Volume +/-، Swipe بأربع اتجاهات، إدخال نص، تغيير الثيم، وإعادة تشغيل الهاتف.
- عرض معلومات الجهاز: serial، model، Android، البطارية، ومقاس الشاشة.

## ملاحظات
- زر **Reboot Phone** يعيد تشغيل الجهاز فعلياً؛ استخدمه فقط عند الحاجة.
- الصورة المؤقتة تُكتب إلى `/tmp/falcon_live.bmp` أثناء التشغيل.
- أغلق التطبيق بزر **Exit App** لتنظيف الذاكرة وإنهاء عمليات الالتقاط.
- للرجوع إلى النسخة التجريبية القديمة: `examples/phone_mirror.mg`.
